# Letter Ledger word list sources

`word-list.json` contains lowercase five-letter, no-repeat entries from the
system Webster's Second International word list. `scowl-word-list.json` adds
missing entries from the English Speller Database (ESDB, previously SCOWL v2),
release `rel-2026.02.25`. The additions were generated from the size 70,
American English (`A`), variant level 1 list, with accents removed and
abbreviations and special categories excluded; only lowercase five-letter
words with no repeated letters and not already in the base list were retained.

Source: [en-wl/wordlist, release rel-2026.02.25](https://github.com/en-wl/wordlist/tree/rel-2026.02.25)
